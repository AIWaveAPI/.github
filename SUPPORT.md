# Support

- **How to use the API**: [aiwave-quickstart](https://github.com/AIWaveAPI/aiwave-quickstart) — runnable curl, Python and Node examples
- **Errors and edge cases**: [Troubleshooting guide](https://github.com/AIWaveAPI/aiwave-quickstart/blob/main/docs/TROUBLESHOOTING.md)
- **What does it cost**: `python3 scripts/cost.py` in the quickstart repo
- **Model list / prices**: https://aiwave.live/models and https://aiwave.live/pricing
- **Questions and discussion**: [GitHub Discussions](https://github.com/AIWaveAPI/aiwave-quickstart/discussions)
- **Bugs**: open a structured issue using the template
- **Security issues**: see [SECURITY.md](SECURITY.md) — do not open a public issue

For account or billing problems, use the console at https://aiwave.live.
